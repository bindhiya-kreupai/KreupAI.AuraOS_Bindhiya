### Backend Microservices Map

| Service | Depends On | Provides To |
|---------|------------|-------------|
| **Employee Service** | Auth, Org | All services |
| **Attendance Service** | Employee, Shift | Payroll, Analytics |
| **Leave Service** | Employee, Policy | Payroll, Analytics |
| **Payroll Service** | Employee, Attendance, Leave, Benefits | Analytics, Banking |
| **Recruitment Service** | Employee, Org, AI | Onboarding |
| **Onboarding Service** | Employee, Recruitment | Core HR |
| **Performance Service** | Employee, Goals | Compensation, Learning |
| **Learning Service** | Employee, Courses | Performance, Analytics |
| **Benefits Service** | Employee, Plans | Payroll |
| **Analytics Service** | All Services | Dashboards, Reports |
| **AI Service** | Analytics, Employee | Predictions, Automation |
| **Workflow Service** | All Services | Approvals, Automation |
| **Notification Service** | All Services | Email, Push, SMS |
