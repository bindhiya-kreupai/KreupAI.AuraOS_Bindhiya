## 📋 Schema Design

### **EmploymentHistory Model**
```prisma
model EmploymentHistory {
  id            String    @id @default(uuid())
  tenantId      String
  employeeId    String

  // Change Details
  changeType    String    // PROMOTION, DEMOTION, TRANSFER, LATERAL_MOVE, NEW_HIRE, TERMINATION, REHIRE
  effectiveDate DateTime
  reason        String?
  notes         String?

  // Previous State (Before Change)
  previousDepartmentId  String?
  previousDepartment    Department? @relation("PreviousDepartment", fields: [previousDepartmentId], references: [id])
  previousPositionId    String?
  previousJobProfileId  String?
  previousJobProfile    JobProfile? @relation("PreviousJobProfile", fields: [previousJobProfileId], references: [id])
  previousGradeId       String?
  previousGrade         Grade? @relation("PreviousGrade", fields: [previousGradeId], references: [id])
  previousLocationId    String?
  previousLocation      Location? @relation("PreviousLocation", fields: [previousLocationId], references: [id])
  previousManagerId     String?
  previousSalary        Decimal? @db.Decimal(15, 2)
  previousEmploymentType String?

  // New State (After Change)
  newDepartmentId       String?
  newDepartment         Department? @relation("NewDepartment", fields: [newDepartmentId], references: [id])
  newPositionId         String?
  newJobProfileId       String?
  newJobProfile         JobProfile? @relation("NewJobProfile", fields: [newJobProfileId], references: [id])
  newGradeId            String?
  newGrade              Grade? @relation("NewGrade", fields: [newGradeId], references: [id])
  newLocationId         String?
  newLocation           Location? @relation("NewLocation", fields: [newLocationId], references: [id])
  newManagerId          String?
  newSalary             Decimal? @db.Decimal(15, 2)
  newEmploymentType     String?

  // Approval Workflow
  requestedBy   String?
  approvedBy    String?
  approvedAt    DateTime?
  status        String    @default("COMPLETED") // PENDING, APPROVED, REJECTED, COMPLETED

  // Metadata
  isAutoGenerated Boolean @default(false) // True if created by system trigger
  createdAt     DateTime  @default(now())
  updatedAt     DateTime  @updatedAt

  @@index([tenantId])
  @@index([employeeId])
  @@index([changeType])
  @@index([effectiveDate])
  @@index([status])
}
```

## 📊 API Endpoints

### **Employment History**
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | /api/v1/employment-history | List all history records with filters |
| POST | /api/v1/employment-history | Create new history record |
| GET | /api/v1/employment-history/:id | Get history record by ID |
| PUT | /api/v1/employment-history/:id | Update history record |
| DELETE | /api/v1/employment-history/:id | Delete history record |
| GET | /api/v1/employment-history/employee/:employeeId | Get timeline for specific employee |
| GET | /api/v1/employment-history/stats | Get statistics (promotions, transfers, etc.) |
| POST | /api/v1/employment-history/compare | Compare two history records |

## 🔄 Change Type Definitions

| Change Type | Description | Typical Fields Changed |
|-------------|-------------|----------------------|
| **PROMOTION** | Vertical move up | Grade, JobProfile, Salary ↑ |
| **DEMOTION** | Vertical move down | Grade, JobProfile, Salary ↓ |
| **TRANSFER** | Department/Location change | Department, Location |
| **LATERAL_MOVE** | Same level, different role | JobProfile (same grade) |
| **NEW_HIRE** | Initial employment | All fields (no previous) |
| **TERMINATION** | Employment ended | All fields (no new) |
| **REHIRE** | Return after termination | All fields |
