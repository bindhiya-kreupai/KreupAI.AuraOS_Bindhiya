## 🗄️ Database Schema Details

### **EmploymentHistory Model** (35 fields)
```prisma
model EmploymentHistory {
  // Identity
  id, tenantId, employeeId

  // Change Details
  changeType // 7 types: PROMOTION, DEMOTION, TRANSFER, LATERAL_MOVE, NEW_HIRE, TERMINATION, REHIRE
  effectiveDate, reason, notes

  // Previous State (Before Change)
  previousDepartmentId, previousDepartment
  previousPositionId, previousJobProfileId, previousJobProfile
  previousGradeId, previousGrade
  previousLocationId, previousLocation
  previousManagerId, previousSalary, previousEmploymentType

  // New State (After Change)
  newDepartmentId, newDepartment
  newPositionId, newJobProfileId, newJobProfile
  newGradeId, newGrade
  newLocationId, newLocation
  newManagerId, newSalary, newEmploymentType

  // Approval Workflow
  requestedBy, approvedBy, approvedAt
  status // PENDING, APPROVED, REJECTED, COMPLETED

  // Metadata
  isAutoGenerated, createdAt, updatedAt
}
```

**Change Types**:
- **PROMOTION** - Vertical move up (higher grade/salary)
- **DEMOTION** - Vertical move down
- **TRANSFER** - Department or location change
- **LATERAL_MOVE** - Same level, different role
- **NEW_HIRE** - Initial employment
- **TERMINATION** - Employment ended
- **REHIRE** - Return after termination

**Status Values**:
- **PENDING** - Awaiting approval
- **APPROVED** - Approved but not yet effective
- **REJECTED** - Rejected by approver
- **COMPLETED** - Change has been completed

## 📈 Change Type Detection Logic

**Suggested algorithm** for auto-determining change type:

```typescript
function determineChangeType(previous: any, updated: any): string {
  // Check grade change
  if (previous.gradeId !== updated.gradeId) {
    const prevGrade = await getGrade(previous.gradeId);
    const newGrade = await getGrade(updated.gradeId);

    if (newGrade.level > prevGrade.level) return 'PROMOTION';
    if (newGrade.level < prevGrade.level) return 'DEMOTION';
  }

  // Check department/location change
  if (previous.departmentId !== updated.departmentId ||
      previous.locationId !== updated.locationId) {
    return 'TRANSFER';
  }

  // Check job profile change (same grade)
  if (previous.jobProfileId !== updated.jobProfileId) {
    return 'LATERAL_MOVE';
  }

  return 'LATERAL_MOVE'; // Default
}
```
