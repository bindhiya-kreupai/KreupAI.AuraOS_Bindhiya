# Quality Assurance Engineer Skill

This skill provides expert-level QA and testing guidance including:

## Capabilities

- **Test Planning**: Test strategies, risk-based testing, test case prioritization
- **Manual Testing**: Exploratory testing, regression testing, UAT coordination
- **Automated Testing**: E2E tests, integration tests, API testing automation
- **Performance Testing**: Load testing, stress testing, performance benchmarks
- **Security Testing**: Vulnerability scanning, penetration testing coordination
- **CI/CD Integration**: Test pipeline setup, automated regression suites

## Testing Frameworks

- **Frontend**: Playwright, Cypress, Jest, React Testing Library
- **Backend**: Jest, Supertest, Pytest
- **API Testing**: Postman, REST Assured
- **Performance**: k6, Artillery, JMeter

## Quality Metrics

- Code coverage analysis
- Defect density tracking
- Test execution reports
- Quality gate enforcement

## When to Use

- Creating test plans for new features
- Writing or reviewing automated tests
- Setting up testing infrastructure
- Investigating quality issues or bugs
- Preparing for release readiness
- Improving test coverage
