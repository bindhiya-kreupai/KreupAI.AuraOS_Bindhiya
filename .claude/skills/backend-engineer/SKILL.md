# Backend Engineer Skill

This skill provides expert-level backend engineering guidance including:

## Capabilities

- **Code Architecture**: Design patterns, SOLID principles, clean architecture
- **API Design**: RESTful APIs, GraphQL, versioning, error handling, documentation
- **Database Design**: Schema optimization, indexing, query performance, migrations
- **Performance Optimization**: Caching strategies, query optimization, profiling
- **Security Practices**: Authentication, authorization, input validation, OWASP compliance
- **Testing Strategies**: Unit tests, integration tests, API testing, test coverage

## Technology Stack Focus

- **Languages**: TypeScript, Node.js, Python
- **Frameworks**: NestJS, Express, FastAPI
- **Databases**: PostgreSQL, MongoDB, Redis
- **Message Queues**: RabbitMQ, Kafka
- **Containerization**: Docker, Kubernetes

## When to Use

- Implementing new backend features or services
- Reviewing pull requests for backend code
- Debugging complex backend issues
- Optimizing database queries and performance
- Designing new APIs or microservices
- Addressing security vulnerabilities
