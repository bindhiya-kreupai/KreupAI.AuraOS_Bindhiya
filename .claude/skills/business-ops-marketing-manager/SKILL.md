# LinkedIn Expert & Content Creator

Create viral, engaging content across LinkedIn, Meta platforms, Google Business, and blogs. Every piece of content must achieve three goals: stop the scroll, deliver value, and drive action.

## Workflow

### 1. Content Brief

Before writing, clarify:

- **Platform**: LinkedIn / Facebook / Instagram / Google Posts / Blog
- **Content Type**: Project showcase, thought leadership, announcement, case study, behind-the-scenes, hiring, celebration
- **Goal**: Brand awareness, lead generation, engagement, traffic, recruitment
- **Audience**: Decision-makers, developers, HR professionals, business owners, etc.
- **Tone**: Professional, conversational, inspirational, educational, storytelling
- **CTA**: What action should readers take?

If context is missing, infer based on content and state assumptions.

### 2. Hook Strategy

The first 2-3 lines determine if anyone reads the rest. Apply the **3-Second Rule**: capture attention before they scroll.

**Power Hook Formulas:**

- **Contrarian**: "Unpopular opinion: [challenge common belief]"
- **Curiosity Gap**: "I spent [X time] doing [Y]. Here's what nobody tells you."
- **Bold Claim**: "[Specific outcome] in [specific timeframe]. Here's how:"
- **Story Open**: "Last week, something happened that changed how I think about [topic]."
- **Direct Value**: "The [X] framework that helped [specific result]:"
- **Pattern Interrupt**: "Stop. Before you [common action], read this."
- **Social Proof**: "[Number] companies are doing [X] wrong. Here's the fix."

### 3. Content Structure

Use platform-appropriate format (see `references/platform-guides.md`):

**LinkedIn/Meta (Short-form)**

```
HOOK (1-2 lines - make them stop scrolling)
↓
LINE BREAK (creates curiosity)
↓
CONTEXT (2-3 lines - set up the story/problem)
↓
VALUE/INSIGHT (5-8 points OR narrative)
↓
TAKEAWAY (1-2 lines - crystallize the lesson)
↓
CTA (question OR action)
↓
HASHTAGS (3-5 relevant, mix of broad + niche)
```

**Blog/Long-form**

```
HEADLINE (benefit-driven, curiosity-inducing)
↓
META DESCRIPTION (150-160 chars, includes keyword + hook)
↓
INTRO (hook + promise + roadmap)
↓
BODY (H2s for each major point, scannable)
↓
CONCLUSION (recap + CTA)
```

### 4. Writing Principles

**Voice & Tone**

- Write like you talk (but polished)
- Use "you" and "I" - make it personal
- Short sentences. Short paragraphs.
- One idea per line on social media
- Read aloud - if you stumble, rewrite

**Engagement Triggers**

- Tell stories (beginning, middle, end)
- Use specific numbers (87%, 3x, $240K)
- Include unexpected details
- Create "aha!" moments
- End with questions (boost comments)

**Psychological Principles**

- **Reciprocity**: Give value first, ask later
- **Social Proof**: "10,000+ users" > "many users"
- **Scarcity**: "Limited spots" / "Last day"
- **Authority**: Credentials, results, experience
- **Likeability**: Be human, share failures too

### 5. Project Showcase Framework

For showcasing projects and client work (see `references/project-showcase.md`):

**The STAR-V Method:**

- **Situation**: What was the client's challenge?
- **Task**: What were we asked to build/solve?
- **Action**: How did we approach it? (tech stack, methodology)
- **Result**: Quantifiable outcomes (%, time saved, revenue)
- **Value**: What can the reader learn/apply?

**Content Angles for Projects:**

1. Problem → Solution journey
2. Behind-the-scenes technical decisions
3. Client success story / testimonial
4. Lessons learned / what we'd do differently
5. Industry insights from the project
6. Team spotlight / collaboration story

## Anti-Patterns to Avoid

**Content Killers:**

- Starting with "I'm excited to announce..." (boring)
- Wall of text without line breaks
- Generic corporate speak
- Asking for engagement without giving value
- Too many CTAs in one post
- Hashtag stuffing at the end
- Humble bragging without insight
- "Comment [X] for the guide" (feels spammy)

**Platform Mistakes:**

- Same content copy-pasted across platforms
- Ignoring platform-specific formatting
- Posting without visuals (where relevant)
- Not responding to comments (kills reach)

## Output Checklist

Before delivering, verify:

- [ ] Hook stops the scroll (would YOU stop?)
- [ ] Value is clear within first 3 lines
- [ ] Content is scannable (line breaks, bullets)
- [ ] Specific numbers/outcomes included
- [ ] CTA is clear and natural
- [ ] Appropriate length for platform
- [ ] Hashtags are relevant and mixed
- [ ] Reads naturally out loud
- [ ] Grammar and spelling checked
- [ ] Visuals suggested (if applicable)
