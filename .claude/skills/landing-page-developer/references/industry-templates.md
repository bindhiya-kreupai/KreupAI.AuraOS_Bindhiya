# Industry Templates Reference

Tailored structures and copy guidance for specific industries.

## SaaS / Software

### Conversion Goal

Free trial signup or demo request

### Recommended Structure

1. Hero with product screenshot
2. Logo strip (B2B credibility)
3. Problem → Solution narrative
4. Feature bento grid (3-6 features)
5. Integration logos
6. Testimonials with job titles
7. Pricing tiers (3 recommended)
8. FAQ
9. Final CTA

### Key Copy Elements

- **Headline formula**: "[Outcome] without [pain point]"
- **CTA**: "Start free trial" / "Get started free" / "Try for free"
- **Social proof**: Number of users, company logos, G2/Capterra ratings
- **Objection handlers**: Security badges, uptime SLA, data migration

### Example Headlines

- "Ship 10x faster with AI-powered workflows"
- "The all-in-one platform for modern teams"
- "Finally, a CRM that doesn't suck"

### Design Notes

- Dark mode often preferred for dev tools
- Product screenshots essential
- Integration ecosystem as trust signal

## E-commerce / DTC

### Conversion Goal

Add to cart or email capture

### Recommended Structure

1. Hero with hero product image
2. "As seen in" press logos
3. Product benefits (lifestyle focus)
4. How it works / ingredients
5. Before/after or comparison
6. Reviews with photos
7. Bundle offers
8. FAQ
9. Limited-time CTA

### Key Copy Elements

- **Headline formula**: "[Benefit] you can [see/feel/taste]"
- **CTA**: "Shop now" / "Add to cart" / "Claim your [product]"
- **Social proof**: Reviews count, celebrity endorsements, user photos
- **Urgency**: Limited stock, sale ending, exclusive access

### Example Headlines

- "The skincare routine that actually works"
- "Premium quality. Half the price."
- "Join 50,000+ happy customers"

### Design Notes

- Lifestyle photography over product shots alone
- Mobile-first (70%+ mobile traffic)
- Sticky add-to-cart on mobile

## Agency / Services

### Conversion Goal

Contact form submission or call booking

### Recommended Structure

1. Hero with bold claim
2. Client logo strip
3. Services overview
4. Case study highlights
5. Process (how you work)
6. Team or founder story
7. Testimonials
8. Contact/booking form

### Key Copy Elements

- **Headline formula**: "We [verb] [outcome] for [audience]"
- **CTA**: "Book a call" / "Get a quote" / "Start your project"
- **Social proof**: Case study results, client testimonials
- **Trust signals**: Years in business, team size, awards

### Example Headlines

- "We build brands that get noticed"
- "Growth marketing for ambitious startups"
- "Digital experiences that convert"

### Design Notes

- Portfolio/case study visuals critical
- Calendly embed for easy booking
- Personal touch (team photos, founder story)

## Mobile App

### Conversion Goal

App store download or waitlist signup

### Recommended Structure

1. Hero with phone mockup
2. App store badges + ratings
3. Feature carousel (3-4 screens)
4. How it works
5. User reviews from app stores
6. Download CTA with QR code

### Key Copy Elements

- **Headline formula**: "[Action] on the go" / "Your [noun] in your pocket"
- **CTA**: "Download free" / "Get the app" / "Join the waitlist"
- **Social proof**: Download count, app store ratings, featured badges
- **Features**: Focus on 3-4 killer features

### Example Headlines

- "Your finances, finally organized"
- "The #1 app for [use case]"
- "Over 1 million downloads"

### Design Notes

- Device mockups essential
- Animated feature demos
- App store badges prominent

## Coming Soon / Waitlist

### Conversion Goal

Email capture

### Recommended Structure

1. Hero with teaser + email capture
2. Problem you're solving
3. Sneak peek (blurred screenshots or features)
4. Founder story or team
5. Final email capture

### Key Copy Elements

- **Headline formula**: "[Outcome] is coming" / "Join the waitlist for [product]"
- **CTA**: "Join waitlist" / "Get early access" / "Be the first to know"
- **Urgency**: Limited spots, founding member perks, launch date
- **Trust**: Team credentials, backed by, previous work

### Example Headlines

- "The future of [category] is almost here"
- "Be the first to experience [product]"
- "Join 5,000+ on the waitlist"

### Design Notes

- Minimal, focused on single email input
- Progress indicator if relevant
- Social proof of waitlist size

## Local Business

### Conversion Goal

Phone call, booking, or directions

### Recommended Structure

1. Hero with location/team photo
2. Services with pricing
3. About / why choose us
4. Reviews (Google/Yelp)
5. Gallery
6. Contact with map

### Key Copy Elements

- **Headline formula**: "[Service] in [Location]"
- **CTA**: "Call now" / "Book appointment" / "Get directions"
- **Social proof**: Google rating, years in business, "locally owned"
- **Trust**: Licenses, certifications, guarantees

### Example Headlines

- "Award-winning dental care in Austin"
- "Your neighborhood plumber since 1995"
- "5-star rated auto repair"

### Design Notes

- Google Maps embed
- Click-to-call buttons (mobile)
- Local imagery over stock photos

## Event / Conference

### Conversion Goal

Ticket purchase or registration

### Recommended Structure

1. Hero with event name, date, location
2. Speaker lineup
3. Schedule/tracks
4. Ticket tiers
5. Sponsor logos
6. Past event gallery/video
7. FAQ
8. Register CTA

### Key Copy Elements

- **Headline formula**: "The [adjective] event for [audience]"
- **CTA**: "Get tickets" / "Register now" / "Save your spot"
- **Urgency**: Early bird pricing, limited seats
- **Social proof**: Past attendee count, notable speakers

### Example Headlines

- "The premier conference for product leaders"
- "3 days. 50 speakers. Unlimited networking."
- "Join 2,000+ developers this March"

### Design Notes

- Video from past events if available
- Speaker cards with photos and credentials
- Countdown timer if appropriate

## Copy Formulas Quick Reference

### Headlines

| Formula                              | Example                                |
| ------------------------------------ | -------------------------------------- |
| [Outcome] without [pain]             | "Scale revenue without hiring"         |
| The [noun] for [audience]            | "The CRM for modern sales teams"       |
| Stop [pain]. Start [benefit].        | "Stop guessing. Start growing."        |
| [Number] [audience] already [action] | "10,000+ teams already ship faster"    |
| Finally, [benefit]                   | "Finally, invoicing that doesn't suck" |

### Subheadlines

| Formula                                        | Example                                      |
| ---------------------------------------------- | -------------------------------------------- |
| [Product] helps you [benefit] in [time/manner] | "Acme helps you close deals 50% faster"      |
| [Adjective] [category] for [audience]          | "Simple project management for remote teams" |
| From [pain state] to [benefit state]           | "From chaos to clarity in minutes"           |

### CTAs by Intent

| Intent     | Primary CTA        | Secondary CTA  |
| ---------- | ------------------ | -------------- |
| Free trial | "Start free trial" | "See pricing"  |
| Demo       | "Book a demo"      | "Watch video"  |
| Purchase   | "Buy now"          | "Learn more"   |
| Download   | "Download free"    | "See features" |
| Waitlist   | "Join waitlist"    | "Learn more"   |
| Contact    | "Get in touch"     | "See our work" |
