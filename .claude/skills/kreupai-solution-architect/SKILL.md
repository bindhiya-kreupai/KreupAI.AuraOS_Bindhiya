# KreupAI Solution Architect Skill

This skill provides expert-level solution architecture guidance for KreupAI products including:

## Capabilities

- **System Architecture Design**: Design scalable, maintainable enterprise architectures
- **Technology Evaluation**: Assess and recommend technology stacks and frameworks
- **Integration Strategy**: Plan API integrations, microservices communication, and third-party integrations
- **Scalability Planning**: Design for horizontal/vertical scaling and high availability
- **Security Architecture**: Implement security best practices and compliance requirements
- **Cloud Architecture**: AWS, Azure, GCP deployment strategies and optimization

## When to Use

- Designing new modules or features for AuraOS
- Evaluating architectural trade-offs
- Planning system integrations
- Reviewing existing architecture for improvements
- Creating technical specifications and design documents
