## Pricing Strategy

### Pricing Model Options

```
PRICING MODELS

1. PER-USER:
   Formula: Users × Price/user/month
   Best for: Collaboration tools, productivity software
   Example: $25/user/month

2. TIERED:
   Formula: Feature bundles at fixed prices
   Best for: Products with clear capability levels
   Example: Starter $99, Pro $299, Enterprise Custom

3. USAGE-BASED:
   Formula: Units consumed × Price/unit
   Best for: APIs, infrastructure, transactions
   Example: $0.01/API call

4. VALUE-BASED:
   Formula: Linked to outcome (revenue, savings, etc.)
   Best for: High-impact solutions with measurable ROI
   Example: 1% of revenue influenced

5. HYBRID:
   Formula: Platform fee + Per-user + Usage
   Best for: Complex enterprise products
   Example: $500/mo platform + $10/user + $0.05/transaction
```

### Pricing Framework

```
PRICING STRATEGY TEMPLATE

VALUE METRIC:
What unit of value does the customer pay for?
• [Per user / Per transaction / Per location / etc.]

PRICE POINT:
How do we position vs. alternatives?
• Below market: Win on volume, prove value first
• At market: Compete on features, win on execution
• Above market: Win on differentiation, premium brand

PACKAGING:
How do we bundle features into tiers?
┌─────────────────────────────────────────────────────────────────────┐
│ STARTER        │ PROFESSIONAL    │ ENTERPRISE                      │
├────────────────┼─────────────────┼─────────────────────────────────┤
│ Core features  │ + Advanced      │ + Premium                       │
│                │ + Integrations  │ + Custom                        │
│ $X/user/month  │ $Y/user/month   │ Custom pricing                  │
│ Up to 10 users │ Up to 100 users │ Unlimited                       │
└────────────────┴─────────────────┴─────────────────────────────────┘

DISCOUNTING:
When and how much?
• Annual prepay: [X]% discount
• Multi-year: [Y]% discount
• Volume: Graduated based on [metric]
• Strategic: Approval required for [Z]%+
```

### Optimization Playbook

```
GTM OPTIMIZATION LEVERS

IF AWARENESS IS LOW:
→ Increase top-of-funnel content
→ Test new channels
→ Boost paid spend
→ Partner co-marketing

IF LEAD QUALITY IS POOR:
→ Refine ICP and targeting
→ Update lead scoring
→ Improve qualification process
→ Adjust messaging

IF CONVERSION IS LOW:
→ Analyze lost deals
→ Improve demo effectiveness
→ Simplify pricing
→ Address common objections

IF DEAL SIZE IS SMALL:
→ Multi-thread in accounts
→ Bundle products
→ Lead with value
→ Train on negotiation

IF CYCLE IS LONG:
→ Create urgency
→ Improve proposal quality
→ Address procurement earlier
→ Offer pilot programs
```
