## Demo Psychology

### The Prospect's Brain During a Demo

```
Minute 0-2:   "Is this worth my time?"           → HOOK or lose them
Minute 2-5:   "Does this apply to me?"           → CONTEXT or they disengage
Minute 5-8:   "Can this actually do what I need?" → WOW MOMENTS or skepticism
Minute 8-10:  "What's the catch?"                → PROOF or hesitation
Minute 10+:   "What do I do next?"               → CTA or lost deal
```

### Three Demo Truths

1. **They don't care about your product**—they care about their problem
2. **Attention is declining**—you have 10 minutes at most, not 30
3. **Decisions are emotional**—logic justifies, emotion decides

## The 10-Minute Framework

### Structure Overview

```
┌─────────────────────────────────────────────────────────────────────┐
│                     KILLER DEMO STRUCTURE                          │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  [0:00-1:00]  THE HOOK                                              │
│              "What if you could [dream outcome]?"                   │
│              Show the end result first                              │
│                                                                     │
│  [1:00-2:30]  CONTEXT BRIDGE                                        │
│              "Most [industry] teams struggle with..."               │
│              Connect to their specific pain                         │
│                                                                     │
│  [2:30-4:30]  WOW MOMENT #1                                         │
│              The "that's exactly what I need" feature               │
│              Pause. Let it sink in.                                 │
│                                                                     │
│  [4:30-6:30]  WOW MOMENT #2                                         │
│              The "I didn't know that was possible" feature          │
│              Address their unspoken wish                            │
│                                                                     │
│  [6:30-8:00]  WOW MOMENT #3                                         │
│              The "this changes everything" feature                  │
│              Connect to business impact                             │
│                                                                     │

│              "Based on what you've seen, I'd suggest..."            │
│              One clear next step                                    │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### Phase Details

#### Phase 1: The Hook (60 seconds)

**Purpose:** Make them WANT to see more

**Formula:**

```
"Before I show you anything, let me ask:
[Rhetorical question about their pain point]?

What if I told you [bold claim with specific outcome]?

Let me show you exactly how that works—I'll keep this to 10 minutes."
```

**Power Hook Examples by Industry:**

| Industry   | Hook                                                                    |
| ---------- | ----------------------------------------------------------------------- |
| HR/HCM     | "What if onboarding a new employee took 10 minutes instead of 3 days?"  |
| Facilities | "What if your maintenance team got alerts BEFORE equipment fails?"      |
| Retail     | "What if you knew which products would sell out... 2 weeks in advance?" |
| Healthcare | "What if patient wait times dropped 60%... without hiring anyone?"      |
| Finance    | "What if month-end close took 2 days instead of 2 weeks?"               |

**Demo Hook Anti-Patterns:**

- ❌ "Let me tell you about our company first..."
- ❌ "I'm going to walk you through our platform..."
- ❌ "Can you see my screen? Let me share..."

#### Phase 2: Context Bridge (90 seconds)

**Purpose:** Prove you understand THEIR world

**Formula:**

```
"Here's what we see with [industry] teams:

The challenge isn't [surface problem].
It's that [deeper problem] which causes [business impact].

Sound familiar? Let me show you how [Product] changes this."
```

**Key Principles:**

- Reference conversations: "You mentioned earlier that..."
- Use industry terminology: "Your [specific role] team probably deals with..."
- Quantify the pain: "Most companies lose [X hours/dollars] because..."

#### Phase 3: Wow Moments (6 minutes total)

**The Wow Moment Formula:**

```
1. STATE the problem: "Right now, you probably [painful current state]..."
2. SHOW the solution: "With [Product], here's what happens..."
3. PAUSE for reaction: [Wait 3 seconds. Let them process.]
4. CONNECT to impact: "That means your team can now..."
```

**Wow Moment Selection Matrix:**

| Wow Moment    | Focus                         | Best For            |
| ------------- | ----------------------------- | ------------------- |
| #1 (Core)     | Solves their #1 stated pain   | Every demo          |
| #2 (Surprise) | Capability they didn't expect | Building desire     |
| #3 (Impact)   | Business-level transformation | Executive audiences |

**Example Wow Moment Script (HCM Product):**

```
WOW MOMENT #1: Self-Service Leave

"Right now, when an employee wants to request leave, what happens?
They email HR... HR checks the calendar... maybe there's back-and-forth...
it takes 2-3 days for something that should take 2 minutes.

[CLICK - Show employee portal]

Here's what your employees see. One click. They see their balance,
team calendar, and... done. Approved in under 30 seconds.

[PAUSE]

That's 15 hours a week your HR team gets back.
What would they do with that time?"
```

#### Phase 4: Proof Layer (60 seconds)

**Purpose:** Remove the "too good to be true" doubt

**Elements:**

- **Similar Customer:** "A [similar company] in [same industry]..."
- **Specific Metric:** "...reduced [process] time by 67%"
- **Timeline:** "...within the first 90 days"
- **Name Drop (if allowed):** "I can connect you with their [title] if helpful"

**Proof Hierarchy:**

1. Named customer with specific results (best)
2. Anonymized customer with specific results (good)
3. Aggregate data across customers (acceptable)
4. No proof (risky—avoid)

#### Phase 5: The Ask (60 seconds)

**Purpose:** Convert interest to action

**Strong Ask Formula:**

```
"Based on what you've seen today, here's what I'd suggest:

[Option A]: A 2-week pilot with your [specific team]
[Option B]: A technical deep-dive with your [IT/Implementation team]

Which feels like the right next step?"
```

**Ask Anti-Patterns:**

- ❌ "What do you think?" (too vague)
- ❌ "Any questions?" (invites objections)
- ❌ "I'll send you some materials..." (loses momentum)

## Industry Demo Templates

### Healthcare Demo Flow

```
HOOK: "What if patient wait times dropped 60%?"
CONTEXT: Fragmented scheduling, no-shows, staff overwhelm
WOW 1: AI-powered appointment optimization
WOW 2: Automated patient reminders (SMS/WhatsApp)
WOW 3: Real-time department load balancing
PROOF: "Regional hospital reduced wait times from 45 to 18 minutes"
ASK: "Pilot in your outpatient department?"
```

### Manufacturing Demo Flow

```
HOOK: "What if you knew about equipment failure 48 hours early?"
CONTEXT: Unplanned downtime costs, reactive maintenance trap
WOW 1: Predictive maintenance dashboard
WOW 2: Automatic work order generation
WOW 3: Spare parts inventory optimization
PROOF: "Reduced unplanned downtime by 73%"
ASK: "Connect sensors to your critical equipment for a 30-day trial?"
```

### HR/HCM Demo Flow

```
HOOK: "What if onboarding took 10 minutes, not 3 days?"
CONTEXT: Paper forms, manual data entry, delayed productivity
WOW 1: Digital onboarding journey (employee sees day-1 ready screen)
WOW 2: Automatic document collection and verification
WOW 3: AI-powered policy Q&A bot
PROOF: "Reduced onboarding time by 85%"
ASK: "Pilot with your next 5 hires?"
```

## Demo Script Structure

### Pre-Demo Checklist

```
□ Test environment loaded with relevant data
□ Customer's industry/terminology known
□ Key stakeholder priorities identified
□ Backup plan if technology fails
□ Clear next step defined
□ Time confirmed (protect the 10 minutes)
```

### Demo Script Template

```markdown
# [PRODUCT] Demo for [CUSTOMER] - [DATE]

## Pre-Demo Context

- Attendees: [Names, titles]
- Known pain points: [List]
- Previous interactions: [Summary]
- Desired outcome: [Specific next step]

## Hook (0:00-1:00)

"[Opening question/statement]"

## Context Bridge (1:00-2:30)

"Here's what we see with teams like yours..."
[Industry-specific pain narration]

## Wow Moment #1: [Name] (2:30-4:30)

Problem: [Current state]
Show: [Click path]
Impact: [Outcome statement]

## Wow Moment #2: [Name] (4:30-6:30)

Problem: [Current state]
Show: [Click path]
Impact: [Outcome statement]

## Wow Moment #3: [Name] (6:30-8:00)

Problem: [Current state]
Show: [Click path]
Impact: [Outcome statement]

## Proof (8:00-9:00)

"[Similar customer] achieved [specific result] in [timeframe]."

## Ask (9:00-10:00)

"Based on what you've seen, I'd suggest... Which works for you?"

## Anticipated Questions

Q: [Expected question]
```

## Objection Handling

### Common Objections & Responses

| Objection                 | Response Pattern                                                                     |
| ------------------------- | ------------------------------------------------------------------------------------ |
| "We've seen this before"  | "What made previous solutions fall short? [Listen] Here's how we're different..."    |
| "Looks complex"           | "On day one, your team uses [simple feature]. We layer in capabilities as you grow." |
| "What about integration?" | "We integrate with [their systems]. [Show integration in demo]"                      |
| "Price?"                  | "Let's first confirm this solves your problem. If it does, we'll find a way."        |
| "Need to think about it"  | "Of course. What specific questions would help you decide?"                          |

### Objection Prevention

Build these into demo naturally:

- **Complexity fear:** Show simple onboarding path
- **Implementation worry:** Mention timeline and support
- **Risk concern:** Reference similar customers
- **Budget anxiety:** Hint at ROI before price comes up

## Virtual vs In-Person

### Virtual Demo Adjustments

```
ATTENTION SPAN: Shorter (8 min max)
ENGAGEMENT: Check in every 2 minutes ("Does this resonate?")
VISUALS: Larger fonts, fewer on-screen elements
TECHNOLOGY: Have backup (screen share fails → phone camera)
FOLLOW-UP: Send recording + 3-bullet summary within 1 hour
```

### In-Person Demo Advantages

```
WHITEBOARD: Draw their current process, then your solution
MULTIPLE SCREENS: Show dashboard while discussing
READ THE ROOM: Adjust based on body language
DEMO HANDOFF: Let them click (ownership builds commitment)
```

## Demo Quality Scorecard

After each demo, score yourself:

| Element     | Question                              | Score (1-5) |
| ----------- | ------------------------------------- | ----------- |
| Hook        | Did they lean in during first minute? |             |
| Context     | Did they say "yes, exactly" or nod?   |             |
| Wow Moments | Were there visible reactions?         |             |
| Proof       | Did proof feel relevant to them?      |             |
| Ask         | Did they commit to a next step?       |             |
| Time        | Did you finish in 10 minutes?         |             |

**Scoring:**

- 25-30: Demo mastery
- 20-24: Good, refine ask
- 15-19: Rebuild context bridge
- Below 15: Restart from scratch
