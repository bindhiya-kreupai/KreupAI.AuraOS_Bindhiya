## Deck Psychology

### Why Most Decks Fail

```
FAILURE MODE #1: Feature Catalog
"Here are 47 features we built..."
RESULT: Audience glazes over

FAILURE MODE #2: No Narrative
Slides feel disconnected
RESULT: Forgettable

FAILURE MODE #3: Weak Close
"Any questions? Here's my email."
RESULT: No next step
```

### The Story Arc

Every pitch deck is a story:

```
ACT 1: THE WORLD HAS A PROBLEM
       → Create tension

ACT 2: A SOLUTION EXISTS
       → Build hope

ACT 3: HERE'S PROOF IT WORKS
       → Establish credibility

EPILOGUE: HERE'S YOUR ROLE
          → Call to action
```

### Slide-by-Slide Guide

#### Slide 1: Title + Bold Claim

**Purpose:** Set the tone, make them curious

**Elements:**

- Company/Product name
- One-line tagline (benefit-focused)
- Bold visual (not a stock photo)

**Examples:**

```
Bad:  "AuraOS - Human Capital Management Platform"
Good: "AuraOS - Hire to Retire in 10 Clicks"

Bad:  "FaciOS - Facility Management Software"
Good: "FaciOS - Your Building Runs Itself"
```

#### Slide 2: The Problem

**Purpose:** Create emotional resonance

**Formula:**

```
[Industry role] spends [shocking amount] of time on [painful task].

The result?
• [Consequence 1]
• [Consequence 2]
• [Consequence 3]

This costs companies [$ amount] every year.
```

**Visual:** Show the pain (stressed employee, cluttered desk, error messages)

#### Slide 3: Problem Amplification

**Purpose:** Make the status quo unacceptable

**Formula:**

```
Current solutions fail because:

❌ [Limitation 1 of competitors/manual process]
❌ [Limitation 2]
❌ [Limitation 3]

The market is stuck in [decade] while [industry] has evolved.
```

**Visual:** Comparison chart showing gap

#### Slide 4: Market Opportunity

**Purpose:** Establish this is a big problem worth solving

**Elements:**

- TAM/SAM/SOM (for investors)
- Market growth rate
- Key drivers (regulation, digital transformation, labor costs)

**Formula:**

```
The [industry] market is [$ size] and growing [%] annually.

Driven by:
→ [Trend 1]
→ [Trend 2]
→ [Trend 3]
```

#### Slide 5: Solution Overview

**Purpose:** The "aha" moment—show the answer

**Formula:**

```
[Product Name] is the [category] that [primary benefit].

Unlike [alternatives], we [key differentiator].

[One screenshot or visual of the product]
```

**Rule:** This slide must be understood in 5 seconds

#### Slide 6: How It Works

**Purpose:** Make it tangible without being technical

**Format:** 3-step process

```
1. [ACTION]        2. [PROCESS]         3. [OUTCOME]
   Icon + 1 line      Icon + 1 line        Icon + 1 line
```

**Example (HCM):**

```
1. ONBOARD           2. AUTOMATE           3. INSIGHTS
   Employee joins       System handles        Leaders see
   in 10 minutes        HR workflows          real-time data
```

#### Slide 7: Key Differentiators

**Purpose:** Answer "why you vs. alternatives?"

**Format:** 3-4 differentiators with proof

```
┌──────────────────────────────────────────────────────────┐
│ Why [Product]?                                           │
├──────────────────────────────────────────────────────────┤
│ ✓ [Differentiator 1]    "Result: [specific outcome]"    │
│ ✓ [Differentiator 2]    "Result: [specific outcome]"    │
│ ✓ [Differentiator 3]    "Result: [specific outcome]"    │
│ ✓ [Differentiator 4]    "Result: [specific outcome]"    │
└──────────────────────────────────────────────────────────┘
```

**Avoid:** Generic claims like "user-friendly" or "scalable"

#### Slide 8: Traction / Case Study

**Purpose:** Prove it works in the real world

**For Early-Stage:**

```
• [X] customers onboarded
• [Y]% monthly growth
• Notable logos (if allowed)
• Pipeline value
```

**For Established:**

```
CASE STUDY: [Customer Name]

Challenge: [Problem]
Solution: [What we did]
Result: [Specific metrics]

"[Quote from customer]" — [Name, Title]
```

#### Slide 9: Team / Credibility

**Purpose:** Prove you can execute

**Elements:**

- Key team members (photo, name, one-line credential)
- Relevant experience ("Ex-[Company]", "Built [Product]")
- Advisors/Investors (if notable)

**For Services:** Include certifications, partnerships, client logos

#### Slide 10: Business Model

**Purpose:** Show how you make money

**For SaaS:**

```
PRICING MODEL
• [Tier 1]: $X/user/month - [Description]
• [Tier 2]: $Y/user/month - [Description]
• [Enterprise]: Custom - [Description]

Average Contract Value: $[ACV]
Gross Margin: [%]
```

**For Services:**

```
ENGAGEMENT MODEL
• Discovery: [X] weeks - $[Y]
• Implementation: [X] months - $[Y]
• Support: Ongoing - $[Y]/month

Typical Project Size: $[Amount]
```

#### Slide 11: The Ask

**Purpose:** Make the request crystal clear

**For Investors:**

```
RAISING $[X] SEED ROUND

Use of Funds:
• [%] Product Development
• [%] Sales & Marketing
• [%] Operations

Timeline: [X] months runway
Target Close: [Date]
```

**For Sales:**

```
NEXT STEPS

Option A: [Pilot program details]
Option B: [Demo/POC details]

Investment: $[Range]
Timeline: [Implementation time]
```

#### Slide 12: Contact + Next Step

**Purpose:** Make it easy to act

**Elements:**

- Contact name, title
- Email, phone
- Website
- Clear CTA: "Schedule a call at [link]"

**Optional:** QR code to calendar booking

## Visual Design Principles

### The 5-Second Rule

Every slide must communicate its point in 5 seconds.

**Test:** Show slide for 5 seconds. Can viewer summarize it?

### Visual Hierarchy

```
HEADLINE (large, bold)
↓
Subtext (medium, supporting)
↓
Visual/Data (takes most space)
↓
Footnote (small, source/caveat)
```

### Color & Typography

```
COLORS
• Primary: Brand color for headlines, CTAs
• Secondary: For supporting elements
• Accent: For data highlights, emphasis
• Background: White or very light (readability)

FONTS
• Headlines: Bold sans-serif, 28-36pt
• Body: Regular sans-serif, 18-24pt
• Captions: Light, 12-14pt

RULES
• Max 3 colors per slide
• Max 2 font families total
• Consistent throughout deck
```

### Data Visualization

```
GOOD DATA SLIDES:
✓ One key insight per chart
✓ Clear labels and titles
✓ Highlight the important number
✓ Source cited

BAD DATA SLIDES:
✗ Multiple charts competing
✗ Tiny labels
✗ No context for numbers
✗ Decoration without meaning
```

## Deck Variants

### Investor Pitch (12-15 slides)

Focus: Growth potential, market size, team, financials
Must have: TAM/SAM/SOM, traction metrics, use of funds, competitive moat

### Sales Pitch (10-12 slides)

Focus: Their problem, your solution, proof it works
Must have: Industry-specific pain, relevant case study, clear pricing/next step

### Partnership Pitch (8-10 slides)

Focus: Mutual benefit, integration ease, go-to-market synergy
Must have: Partner value prop, technical compatibility, revenue model

### Board/Executive Update (8-10 slides)

Focus: Progress against goals, key metrics, decisions needed
Must have: KPIs vs. targets, wins/challenges, asks

## Delivery Tips

### Before Presenting

```
□ Know your audience (titles, concerns, decision criteria)
□ Customize 3+ slides for their industry/situation
□ Practice out loud (not in your head)
□ Prepare for top 5 likely questions
□ Have backup slides for deep dives
□ Test technology (projector, video call, etc.)
```

### During Presentation

```
PACING
• 1-2 minutes per slide max
• Pause after key points
• Check in: "Does this resonate?"

ENERGY
• Stand if possible
• Make eye contact
• Vary your tone

INTERACTION
• Invite questions (but manage time)
• Note objections for later
• Read the room (skip if losing them)
```

### After Presenting

```
FOLLOW-UP (within 24 hours):
• Thank you email
• PDF of deck (no edits)
• Clear next step with date
• Answer any open questions

TRACKING:
• Who opened the deck
• Which slides got most time
• Questions that came up
```

## Deck Quality Scorecard

| Element         | Question                       | Score (1-5) |
| --------------- | ------------------------------ | ----------- |
| Problem         | Is the pain visceral?          |             |
| Solution        | Is it clear in 5 seconds?      |             |
| Differentiation | Is "why you" obvious?          |             |
| Proof           | Is traction credible?          |             |
| Ask             | Is the next step clear?        |             |
| Visual          | Is it professionally designed? |             |
| Story           | Does it flow as a narrative?   |             |
| Time            | Is it 15 minutes or less?      |             |

**Scoring:**

- 35-40: Deck excellence
- 28-34: Good, polish visuals
- 20-27: Rebuild problem/solution
- Below 20: Start from scratch
