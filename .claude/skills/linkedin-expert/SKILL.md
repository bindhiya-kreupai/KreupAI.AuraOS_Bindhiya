## Quick Workflow

### 1. Discovery (Before Creating Anything)

**Gather these inputs:**

```
PRODUCT CONTEXT
├── What does the product do? (3-sentence elevator pitch)
├── What problem does it solve? (pain points)
├── Who is the target buyer? (persona, title, industry)
├── What's the competitive landscape? (alternatives)
└── What's the price point? (and value multiplier)

DELIVERABLE CONTEXT
├── Which deliverable? (demo / deck / case study / GTM)
├── Specific industry vertical? (healthcare, retail, manufacturing, etc.)
├── Stage of deal? (cold outreach, warm lead, late-stage evaluation)
└── Time constraint? (10-min demo, 15-slide deck, etc.)
```

If context missing, ask targeted questions before proceeding.

### 2. Deliverable Selection

```
QUESTION: "What will move this prospect to the next stage?"
         ↓
┌────────────────────────────────────────────────────────────────────────┐
│ Stage          │ Best Deliverable       │ Why                         │
├────────────────┼────────────────────────┼─────────────────────────────┤
│ Awareness      │ Pitch Deck             │ Educate on problem & vision │
│ Interest       │ Demo Flow              │ Show product in action      │
│ Evaluation     │ Case Study             │ Prove ROI with evidence     │
│ Decision       │ Custom POC Scenario    │ Simulate their exact use    │
│ Expansion      │ GTM for New Segment    │ Plan growth into adjacent   │
└────────────────────────────────────────────────────────────────────────┘
```

### 3. Execution Framework

**The 3C Principle for All Deliverables:**

1. **CONTEXT**: Start with their world, not yours
   - Industry pain points they live with daily
   - Competitive pressure they face
   - Regulatory/compliance constraints

2. **CAPABILITY**: Show what you do (not how it works)
   - Features translated to outcomes
   - "This saves 40% of admin time" > "This has automated workflows"
   - Specific to their use case

3. **CONVERSION**: Make the next step obvious
   - Clear CTA (call, POC, pilot, purchase)
   - Remove friction (offer to set up, provide resources)
   - Create urgency (limited pilot slots, pricing deadline)

## Deliverable Summaries

### Killer Demo Flow

**Purpose:** Convert interested prospects to active evaluators
**Duration:** 8-12 minutes
**Structure:** Hook → Context → 3 Wow Moments → Proof → CTA
**Key Metric:** Prospect asks "Can we try this?"
→ Full guide: `references/demo-flow.md`

### Industry-Specific Pitch Deck

**Purpose:** Win mindshare and advance to demo/meeting
**Length:** 10-15 slides
**Structure:** Problem → Vision → Solution → Proof → Ask
**Key Metric:** Meeting booked for next step
→ Full guide: `references/pitch-deck.md`

### Case Study Mock Scenario

**Purpose:** Prove ROI and reduce perceived risk
**Format:** Narrative + Data + Testimonial
**Structure:** Challenge → Solution → Results → Learnings
**Key Metric:** Objection "prove it works" eliminated
→ Full guide: `references/case-study.md`

### GTM Strategy

**Purpose:** Systematically capture market opportunity
**Components:** Positioning + Channels + Pricing + Launch Plan
**Structure:** Market → Message → Motion → Metrics
**Key Metric:** Scalable, repeatable customer acquisition
→ Full guide: `references/gtm-strategy.md`

## Anti-Patterns to Avoid

**Demo Killers:**

- Starting with company history (nobody cares yet)
- Feature tours without context (so what?)
- No clear "aha moment" (forgettable)
- Ending without next step (lost momentum)

**Pitch Deck Sins:**

- Too many slides (attention dies after 10)
- Walls of text (it's a visual medium)
- No competitive positioning (why you?)
- Weak ask (mumbling about "partnership")

**Case Study Mistakes:**

- Fake-sounding testimonials (be specific or skip)
- Vague metrics ("improved efficiency")
- No before/after comparison (show the delta)
- Missing implementation context (how hard was it?)

**GTM Failures:**

- Boiling the ocean (too many segments)
- No channel focus (spreading thin)
- Pricing without value anchor (seems arbitrary)
- No success metrics defined (can't measure, can't improve)

## Output Quality Checklist

Before delivering any material:

- [ ] **Customer-first language**: "You get..." not "We provide..."
- [ ] **Specific numbers**: "$340K saved" not "significant savings"
- [ ] **Industry relevance**: Terms they use, problems they have
- [ ] **Clear next step**: One CTA, not three
- [ ] **Objection preemption**: Address top 3 concerns proactively
- [ ] **Time-appropriate**: Respects the format constraints
- [ ] **Visually scannable**: Key points obvious at a glance
- [ ] **Competitive awareness**: Why you vs. alternatives clear
